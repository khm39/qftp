Web クライアント SPA

作成日: 2026-09-03 更新日: 2026-09-03

概要

画面名

Web クライアント(単一ページアプリケーション)。Phase 7。

画面ID

SCR-WEB-001 非対応表示 / SCR-WEB-002 ログイン / SCR-WEB-003 ファイルブラウザ。ルーティングは / のみ(状態で切替)。

目的

ブラウザから一覧・ダウンロード・アップロード・ディレクトリ作成・名前変更・削除を行う。

利用ユーザー

トークンを配布されたブラウザ利用者。

画面遷移

遷移元

ブラウザで SPA の URL を開く。

遷移先

  • 非対応(WebTransport グローバルなし)→ 終端。
  • ログイン → 接続成功 → ファイルブラウザ。
  • ファイルブラウザ → セッション断 / Disconnect → ログイン。

遷移図

[非対応] (WebTransport なし)
[ログイン] --接続成功--> [ファイルブラウザ] --切断/Disconnect--> [ログイン]

レイアウト

レイアウト概略

ヘッダ(接続先・ユーザ・Disconnect)、ツールバー(Up / パス / New folder / Refresh / Upload)、一覧テーブル、転送キュー(進捗)、ログパネル。

UI要素

入力要素

  • ログイン: サーバ URL(既定は配信元ホスト + WebTransport ポート)、トークン(password 型)。
  • ファイルブラウザ: ファイル選択 / ドラッグ&ドロップ、New folder 名、Rename 新名称。

ボタン・アクション

  • Connect / Disconnect、Up、Refresh、New folder(Mkdir)、Upload(Put、再開対応)、行クリック(Cd または Get)、Rename、Delete(Rm / Rmdir)、Cancel(転送中断)。
  • 追加候補: Quota 表示、Stat 詳細。

表示要素

一覧テーブル(名前、種別、サイズ、更新日時、mode)、ページネーションは自動で全ページ取得(または「さらに読み込む」)。転送ごとの進捗バー(バイト数・速度)。ログ(直近 200 行)。

状態と振る舞い

画面状態

  • ログイン: 初期 / 接続中 / エラー(origin 拒否・トークン不正・証明書)。
  • ブラウザ: 読み込み中 / 空ディレクトリ / 一覧 / エラー(権限、切断)。
  • 転送: キュー待ち / 進行中 / 検証中 / 完了 / 失敗(トレーラ不一致など)。

動的挙動

Refresh の競合はジェネレーションカウンタで古い応答を破棄。アップロードは順次(将来は並列度 2〜4)。ダウンロードはストリーミング保存(File System Access API があれば直接書込、なければチャンク Blob)。

データ・API連携

表示データの取得元

WebTransport 経由の qftp/1(Ls / Stat / Get)。/config.json(証明書ハッシュ・ポート)。

更新操作の送信先

qftp/1(Put / Mkdir / Rename / Rm / Rmdir)。

取得失敗時の挙動

ErrorCode を人が読める文言に変換して表示(message は表示しない、仕様どおり)。RateLimited は RetryAfter 後に自動再試行。切断はログイン画面へ戻り、直前のパスを保持。
