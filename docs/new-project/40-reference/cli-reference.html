共通規約

規約内容
出力先結果(一覧、統計、--json)は stdout。診断・警告・進捗バーは stderr。進捗バーは stderr が TTY のときだけ
終了コードsysexits 準拠(下表)。すべての経路(REPL / one-shot / batch)で同じ対応
エラー文言qftp: <動詞> <対象>: <理由>。理由は ErrorCode の名前と、あれば details(InvalidRange: offset 10 > size 5)。サーバの message は -v のときだけ付記
リモートパスqftp://[user@]host[:port]/path、または alias:/path(: 以降省略時は /)。エイリアスは設定ファイルの [host.*]
ローカルパスREPL では lcd で変えたローカル cwd 基準。~/ 展開。glob は put / mput のローカル引数のみ(クォートで抑止)
クォートREPL 行はシェル風に分割: 空白区切り、'…'、"…"、\ エスケープ。! 行は分割せず丸ごとシェルへ
非 Unix起動時に qftp: unsupported platform で終了コード 70(ADR-011)

終了コード

コード名前いつ
0OKすべて成功
64EX_USAGE引数 / URL / 設定ファイルの誤り、未知エイリアス、サーバの Malformed
65EX_DATAERR転送失敗、サーバの 4xx / 5xx(下記以外)、チェックサム不一致、プロトコルエラー、batch の失敗あり
69EX_UNAVAILABLE接続不能(全アドレス失敗、ALPN 不一致、アイドル切断)
70EX_SOFTWARE内部エラー、非対応プラットフォーム
74EX_IOERRローカルファイル / 設定書込の I/O エラー
77EX_NOPERMUnauthorized、PermissionDenied、mTLS 拒否(close 0x101)、TOFU 不一致

qftp-server

qftp-server [--config <path>] [フラグ…]
qftp-server --check-config [--config <path>] [フラグ…]
qftp-server --generate-completions <bash|zsh|fish|powershell>
qftp-server --version | --long-version

フラグは設定リファレンスのキーと 1:1 で対応します(例: limits.max_connections → --max-connections)。フラグは設定ファイルの値を上書きします。終了コード: 0 正常終了(シグナルによる graceful を含む)、1 設定 / 起動失敗、2 実行時致命エラー(bind 喪失など)。

シグナル動作
SIGTERM / SIGINTgraceful shutdown(新規拒否 → 転送完了待ち → shutdown_timeout で強制)
SIGHUP将来: users.toml 再読込。MVP では無視

qftp-client: 起動形態とグローバルフラグ

qftp-client [フラグ…] [TARGET]                       # REPL(TARGET 省略時は 127.0.0.1:4433)
qftp-client [フラグ…] -e "<cmd>" [-e "<cmd>"…] TARGET  # コマンド列を実行して終了
qftp-client [フラグ…] --batch TARGET < script          # stdin から 1 行 1 コマンド(非 TTY なら自動)
qftp-client [フラグ…] <SUBCOMMAND> …                   # one-shot
フラグ引数意味
--configpath設定ファイル(既定 ~/.qftp/config.toml)
--hosthost[:port]接続先を上書き(IPv6 は [::1]:4433)
--server-namenameSNI とホスト名検証の名前
--capathCA バンドル。指定時は TOFU 無効
--insecure証明書検証なし(開発用)。警告を出す
-T, --trust-on-first-useTOFU。初回は対話で確認、非対話では拒否
--tofu-accept-new非対話でも初回 pin を自動受理
--known-hostspath既定 ~/.qftp/known_hosts
--no-zero-rttチケットの再開を使わない(保存もしない)
--session-ticket-dirpath既定 ~/.qftp/session-tickets
--client-cert / --client-keypathmTLS(対で必須)
--bwlimitrate上下双方向の帯域上限(1M、512Ki)
--no-compresszstd を使わない(Get の accept_encoding を空に、Put を Identity に)
--jsonone-shot の結果を 1 行 JSON で stdout に出す(スキーマは §6)
-q / -v(重ね可)警告のみ / info / debug / trace
-e, --executecmdREPL コマンドを実行して終了(反復可)
--batchstdin から実行
--fail-fast / --no-fail-fastbatch / -e で最初の失敗で止める(既定 on)
--historypath既定 ~/.qftp_history
--generate-completionsshell

qftp-client: one-shot サブコマンド

サブコマンド引数オプション動作
lsREMOTE-l(詳細)、-a(temp を含めない、常に)全ページを取得して表示
statREMOTE1 件のメタデータ
getREMOTE [LOCAL]-r(Phase 5)、-n/--no-clobber、-f/--force、-i/--interactive、--dry-runLOCAL 省略時はリモートの basename。既存があれば上書き規則に従い、規則が「再開」なら自動再開
putLOCAL… REMOTE同上REMOTE が / で終わる、または LOCAL が複数ならディレクトリ扱い。partial があれば再開
mkdir / rmdir / rmREMOTE
renameFROM TO同一ホスト(同一 alias または同一 host:port)必須
chmodMODE REMOTE8 進
quotaREMOTE(ホストのみ)
sync(Phase 6)LOCAL_DIR REMOTE--delete、--dry-runローカル → リモート一方向。.qftpignore。--checksum はない(ADR-010)
watch(Phase 6)LOCAL_DIR REMOTE--debounce <dur>変更を反映(Mkdir を含む)。再接続バックオフ 1→30 s

上書き規則(get / put 共通)

指定既存ローカル(get)/ 既存リモート(put)動作
-nありスキップ(終了コード 0、stderr に skipped)。put は no_clobber=true をワイヤにも載せる
-fあり0 から上書き(get はローカル削除、put は offset 0)
-i または TTYありoverwrite / resume / skip? を尋ねる。resume は長さが小さいときのみ提示
指定なし・非 TTYあり再開(get: ローカル長から、put: partial から)。再開できない(既存が完全 / 同サイズ)ならスキップ
任意なし転送

qftp-client: REPL コマンド

コマンド構文動作
ls / dirls [-l] [path]全ページ取得。-l で mode / uid / gid / mtime を表示
cdcd [path]省略は /
pwd仮想絶対パス
getget [-r] [-n|-f] <remote> [local]one-shot と同じ規則。既定は確認(TTY)
put / mputput [-r] [-n|-f] <local-glob>… [remote]複数一致時は remote をディレクトリ扱い(1 つの remote ファイルへ順に上書きしない)
mgetmget <remote-glob> [local-dir]glob は最後の要素のみ。ディレクトリはスキップ
mkdir / rmdir / rm / delete<path>
rename / mv<from> <to>
chmod<octal> <path>
stat<path>
quota
lcd / lpwd / lls / lmkdirローカル側(プロセスの cwd は変えない)
!!cmd… / !$SHELL -c(ローカル cwd で)。単独 ! は対話シェル
statsセッション統計(上下バイト、ファイル数、失敗数、平均速度)
help / ?[cmd]
quit / exitQuit を送って終了

未知コマンドと引数不足は stderr に使い方を出し、REPL では続行、batch / -e では fail_fast に従います。転送中の Ctrl-C は現在のストリームを reset して Quit を送り、65 で終了します。

出力形式

ls(既定)

-rw-r--r--   1024  2026-09-03 12:34  report.pdf
drwxr-xr-x      -  2026-09-03 12:00  docs/

qftp-admin

qftp-admin [--users <path>] [--tokens <path>] [--mode <octal>] <SUBCOMMAND>
  init-users
  add-user <name> [--home <path>] [--read=<bool>] [--write] [--delete] [--mkdir] [--rmdir] [--rename] [--chmod] [--quota <size>]
  remove-user <name>
  list-users [--json]
  set-permissions <name> [--read <bool>] … [--chmod <bool>]
  set-quota <name> (--bytes <size> | --unlimited)
  set-anonymous (--home <path> [--read=<bool>] … | --remove)
  token add <user> [--label <text>]        # 平文トークンを 1 回だけ stdout に出す
  token revoke (<label> | --user <user> --all)
  token list [--json]
  check                                     # 両ファイルをサーバと同じ検証器で検証
  generate-completions <shell>

終了コード: 0 / 64 usage / 65 検証失敗(重複、未知ユーザ、home の入れ子など)/ 74 I/O。書込は同一ディレクトリの temp に書いて fsync し rename、モードは --mode(既定 0600)。
