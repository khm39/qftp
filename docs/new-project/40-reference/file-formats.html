users.toml

# users.toml
[anonymous]                      # 任意。省略時: home = root、read のみ、quota なし
home = "public"
permissions = { read = true }

[[users]]
name = "alice"                   # 必須。空白のみ・"anonymous" は不可。大文字小文字は区別
home = "alice"                   # 任意。相対 → <root>/alice、省略 → <root>/<name>、絶対パス可
permissions = { read = true, write = true, delete = false, mkdir = true, rmdir = false, rename = false, chmod = false }
quota_bytes = 1073741824         # 任意。0 は不可(無制限は省略で表す)

[[users]]
name = "bob"
permissions = { read = true }
検証違反時
未知キーエラー
permissions の未指定キーfalse
相対 home に .. を含むエラー
home が root の外(canonicalize 後)エラー
write 権限を持つ 2 ユーザの home が同一または入れ子(anonymous を含む)エラー(クォータカウンタが独立なため)。read-only の anonymous の home は他ユーザの home を含んでよい(ADR-015)
name の重複エラー
quota_bytes = 0エラー
home が存在しないサーバ起動時に作成(0750)

mTLS の identity は証明書の SAN(dNSName → rfc822Name → URI)→ CN の順で候補を作り、name と完全一致(前後空白は除去)で照合します。複数ユーザに一致する証明書は拒否されます。

tokens.toml

# tokens.toml(qftp-admin token add が生成。手編集は check で検証すること)
[[tokens]]
user = "alice"
label = "laptop"                                   # user 内で一意(revoke は --user と組で指定)
sha256 = "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08"
created = "2026-09-03T00:00:00Z"                   # RFC 3339
# expires = "2027-09-03T00:00:00Z"                 # 任意
項目規定
トークン本体32 バイトの乱数を base64url(パディングなし、43 文字)で表した文字列。token add の stdout にだけ現れる
保存sha256(token 文字列の UTF-8) を小文字 hex 64 桁で保存(ADR-012)
照合受信文字列を SHA-256 し、全エントリと定数時間比較(早期終了しない)。一致したエントリの user が users.toml に存在しなければ拒否
検証user の存在、label の一意性、hex の長さ、未知キー
失効エントリ削除(token revoke --user <user> <label>)または expires。再読込は再起動(将来 SIGHUP)

known_hosts

# ~/.qftp/known_hosts — 1 行 1 ホスト。# 以降はコメント
files.work.example:4433 sha256:3b1f…e9a0
[2001:db8::1]:4433 sha256:77c2…01aa
home.lan:4433 sha256:0c9d…4e21   # 2026-09-03 に pin
項目規定
キー接続に使った host:port の文字列(SNI ではない)。IPv6 は […]:port。大文字小文字はそのまま
値leaf 証明書 DER の SHA-256、小文字 hex 64 桁、sha256: 接頭辞
照合先頭から最初に一致した行。複数行の同一ホストは許さない(追記時に既存行があれば置換ではなくエラー)
不正行警告して無視(-v で行番号)
追記flock で排他、0600、末尾に 1 行。ホスト文字列に空白・改行・# を含む場合は拒否(インジェクション防止)
不一致接続を閉じ(データ未送出)、SSH 風バナー + 実際に使ったファイルパスを表示、終了コード 77

セッションチケット(V2)

項目規定
ファイル名<host_port>.ticket。host_port の : / \ [ ] は _ に置換
書込同一ディレクトリの temp(pid + 連番)に書き 0600 にして rename
TTL24 時間。created が未来(5 分超)または期限切れなら破棄
pin 検査接続後の leaf SHA-256 が leaf_sha256 と異なれば破棄して警告
保存条件zero_rtt = true かつ CA / システムルート検証モード(TOFU / insecure では保存しない)
旧形式QFT1、ヘッダなしの blob は読まずに削除

その他の規則

項目規定
アップロード temp<final>.qftp.partial(同じディレクトリ)。TempName::is_temp が唯一の判定。Ls 非表示、Get / Rm / Rename / Put の対象名として拒否(PermissionDenied)。起動時に 24 時間超のものを掃除
Ls カーソルbase64url(最後に返したエントリ名)(ADR-008)。パディングなし。復号不能・ソート順に矛盾は Malformed
永続自己署名cert.pem / key.pem(ECDSA P-256、有効期間 1 年、SAN = localhost + bind アドレス)。期限切れ・解析不能なら再生成し、fingerprint をログに出す
履歴1 行 1 コマンド、UTF-8、最大 10,000 行(超過は古い順に削除)。失敗したコマンドも記録
設定の秘密config.toml に鍵を書く仕組みはない(パスのみ)。--check-config の出力にもパスだけが載る
